# Стековая машина (постфиксная нотация)

Скрипт вычисляет выражения в постфиксной записи и показывает состояние стека на каждом шаге.

Поддерживаются операции `+`, `-`, `*`, `/` и специальный оператор `~`:
- Если оба числа не равны 0, считает `|x - y|`.
- Если хотя бы одно равно 0, складывает вообще все числа из стека (включая взятые для операции) и возводит сумму в квадрат.

## Как запустить

Перейдите в папку проекта:
```bash
cd postfix_notation
```

Запустите main.py и передайте выражение в кавычках (кавычки нужны, чтобы терминал не воспринял * и ~ как системные символы):

```bash
python main.py "3 0 4 ~ 2 ~"
```

Вывод программы:

    Шаг '3': стек [3]
    Шаг '0': стек [3, 0]
    Шаг '4': стек [3, 0, 4]
    Шаг '~': стек [49]
    Шаг '2': стек [49, 2]
    Шаг '~': стек [47]
    3 0 4 ~ 2 ~ = 47

## Как запустить тесты

Установите pytest и плагин для проверки покрытия:
```Bash
pip install pytest pytest-cov
```

Запустите проверку:
```Bash
pytest --cov=main
```
